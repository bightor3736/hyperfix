================================================================================
1. WAT IS HYPERFIX?
================================================================================

Hyperfix is een hyperfixatie-tracker — een dagboek voor je huidige obsessie.
De app is gemaakt voor mensen die niet meer kunnen stoppen met praten over
het ding waar ze op dit moment helemaal in opgaan: het nummer dat al twee
weken op repeat staat, de serie die hun hersenen heeft hergeprogrammeerd,
de fanfic die ze voor de zesde keer herlezen, het K-pop bandlid waar ze
ineens alles van willen weten, het personage uit een game waar ze geen
slaap meer voor krijgen.

De grondgedachte: een hyperfixatie is een tijdelijk, intens fenomeen.
Het begint plotseling, eet je hersenen op, en op een dag is het weg.
Hyperfix maakt dat hele bewustzijnsproces zichtbaar — je telt de dagen,
logt dagelijks hoe erg het is op een schaal van 1 tot 10, deelt het met
vrienden via mooie 9:16 cards (voor Stories), en wanneer de fix eindelijk
sterft schrijf je een eulogy (lijkrede) die in "the graveyard" terechtkomt.

De doelgroep is overduidelijk: Gen Z, ADHD-community, fandom-cultuur,
BookTok, K-pop fans, anime kijkers, fanfic lezers, gamers, serie-bingers.
Iedereen die zichzelf herkent in "ik kan nergens anders aan denken".

De tone of voice is droog, zelfbewust, ironisch melancholisch. Phrases
als "the chronically unwell", "send help", "still counting", "log it,
count it, mourn it" — het ding maakt grapjes over hoe ongezond intens
hyperfixaties kunnen zijn zonder ze ooit te pathologiseren.

De pitch: "The journal for your obsession. Log it. Count the days.
Share the card. Mourn it when it ends. Free forever."


================================================================================
2. TECHNISCHE STACK
================================================================================

Hyperfix is gebouwd als moderne web-app met server-side rendering en is
volledig installeerbaar als PWA (Progressive Web App).

Frontend & framework:
  - Next.js 16.2.6 (App Router, server components, edge runtime)
  - React 19.2.6
  - TypeScript 5.6.3 (strict mode overal)
  - Tailwind CSS 3.4.15 (custom config, gecombineerd met inline styles
    voor de brand-tokens zoals teal #5EEAD4)

Lettertypes (via Google Fonts, geladen door next/font):
  - Fraunces — display serif, variabele as voor optical sizing en SOFT,
    gebruikt voor koppen, day counters en titels
  - Instrument Sans — moderne sans-serif voor body tekst en knoppen
  - JetBrains Mono — monospace voor labels, counters, kleine tags

Backend & database:
  - Supabase als alles-in-een backend
    - PostgreSQL database met Row Level Security (RLS) op elke tabel
    - Supabase Auth voor login (email/wachtwoord + OAuth)
    - Supabase Storage voor uploads (banner-afbeeldingen)
    - Realtime subscriptions voor reacties en berichten
  - @supabase/supabase-js 2.105.4
  - @supabase/ssr 0.10.3 voor server-side cookies

Betalingen:
  - Stripe v22.1.1 voor Pro-abonnementen
  - Pro kost $5/maand of $39/jaar (~33% korting op de jaartarief)
  - Stripe Checkout voor het afsluiten, Stripe Webhook voor synchroniseren

E-mail:
  - Resend v6.12.3 voor transactionele e-mails
    (verificatie, wachtwoord reset, welkom, nieuwsbrief)

Push notificaties:
  - Web Push v3.6.7 + service worker (public/sw.js)
  - VAPID-keys voor het ondertekenen van pushes
  - Push subscriptions opgeslagen in eigen tabel

AI:
  - @anthropic-ai/sdk v0.96.0 (Claude API)
  - Gebruikt voor het automatisch genereren van eulogies (Pro-feature)

Beeldgeneratie:
  - Next.js Edge Image Response (next/og) voor dynamische 9:16 share cards,
    OG-afbeeldingen voor social media, slides voor TikTok/Instagram

Analytics:
  - Vercel Analytics v2.0.1
  - Eigen referral-tracking via AffTracker component

Overige utilities:
  - clsx en tailwind-merge voor className composities
  - react-iconly voor een deel van de iconenset
  - Eigen LandingIcons en MilestoneIcons als custom SVG-bibliotheken

Deployment:
  - Vercel (Next.js native)
  - Supabase (managed database & auth)

5. DATABASE-SCHEMA (Supabase PostgreSQL)
================================================================================

Twaalf tabellen, allemaal met Row Level Security (RLS) aan.

--- 5.1 profiles ---

  id                   uuid (verwijst naar auth.users), primary key
  username             text, uniek
  display_name         text
  avatar_url           text
  bio                  text
  is_public            boolean, default true
  is_pro               boolean, default false
  stripe_customer_id   text
  stripe_subscription_id  text
  referral_code        text, uniek
  referred_by          uuid (verwijst naar profiles.id)
  referral_count       int, default 0
  banner_url           text
  pinned_fix_id        uuid (legacy single pin)
  pinned_fix_ids       uuid[] (Pro-feature: tot 3 pinned fixes)
  accent_color         text (Pro)
  timezone             text, default 'UTC'
  notification_prefs   jsonb, default {}
  created_at           timestamptz

--- 5.2 fixes ---

  id                   uuid, primary key
  user_id              uuid (profiles.id, cascade on delete)
  title                text
  category             text, default 'other'
  status               text, default 'Day 1'
  intensity            int, 1-10, default 5
  note                 text
  eulogy               text
  cover_url            text
  banner_url           text
  card_style           text ('paper' | 'dark' | 'minimal' | 'photo')
  tags                 text[]
  is_public            boolean, default false
  started_at           timestamptz, default now()
  ended_at             timestamptz (null als actief)
  created_at           timestamptz

--- 5.3 fix_entries (dagelijkse check-ins) ---

  id                   uuid, primary key
  fix_id               uuid
  user_id              uuid
  date                 date, default current_date
  intensity            int, 1-10 (check-constraint)
  note                 text
  created_at           timestamptz
  UNIQUE (fix_id, date)   -- één check-in per dag per fix

--- 5.4 fix_reactions ---

  id                   uuid, primary key
  fix_id               uuid
  user_id              uuid
  emoji                text
  created_at           timestamptz
  UNIQUE (fix_id, user_id, emoji)

--- 5.5 follows ---

  id                   uuid, primary key
  follower_id          uuid
  following_id         uuid
  created_at           timestamptz
  UNIQUE (follower_id, following_id)
  CHECK (follower_id != following_id)

--- 5.6 notifications ---

  id                   uuid, primary key
  user_id              uuid
  type                 text ('reaction', 'follow', 'milestone',
                            'message', 'streak')
  actor_id             uuid (null toegestaan)
  fix_id               uuid (null toegestaan)
  emoji                text (null toegestaan)
  read                 boolean, default false
  created_at           timestamptz

--- 5.7 fix_comments ---

  id                   uuid, primary key
  fix_id               uuid
  user_id              uuid
  content              text (1–500 tekens)
  created_at           timestamptz

--- 5.8 fix_lists ---

  id                   uuid, primary key
  user_id              uuid
  name                 text
  description          text
  is_public            boolean, default true
  created_at           timestamptz
  updated_at           timestamptz

--- 5.9 fix_list_items ---

  id                   uuid, primary key
  list_id              uuid
  fix_id               uuid
  note                 text
  sort_order           int, default 0
  added_at             timestamptz
  UNIQUE (list_id, fix_id)

--- 5.10 fix_studio_blocks (rich content) ---

  id                   uuid, primary key
  fix_id               uuid
  user_id              uuid
  type                 text ('note' | 'link' | 'image')
  content              jsonb
  sort_order           int
  created_at, updated_at

--- 5.11 conversations (DMs) ---

  id                   uuid, primary key
  user_a               uuid
  user_b               uuid
  last_message_at      timestamptz
  created_at           timestamptz
  CONSTRAINT: user_a < user_b  -- deterministische volgorde
  UNIQUE (user_a, user_b)

--- 5.12 messages ---

  id                   uuid, primary key
  conversation_id      uuid
  sender_id            uuid
  body                 text (1–2000 tekens)
  read                 boolean, default false
  created_at           timestamptz

--- 5.13 push_subscriptions (PWA) ---

  id                   uuid, primary key
  user_id              uuid
  endpoint             text, uniek
  p256dh               text
  auth                 text
  created_at           timestamptz

--- 5.14 waitlist ---

  id                   uuid, primary key
  email                text, uniek
  source               text, default 'landing'
  created_at           timestamptz

Belangrijke RLS-regels:
- Publieke fixes en publieke profielen zijn voor iedereen leesbaar.
- Privé-fixes alleen voor de eigenaar.
- Iedere gebruiker mag alleen zijn eigen data muteren.
- Notifications worden vanuit de service-role key geschreven
  (background jobs / API-routes met admin-client).

7. KERN-FEATURES IN DETAIL
================================================================================

--- 7.1 Fix-levenscyclus ---

1) Aanmaken
   Titel (verplicht), categorie (dropdown: song, show, film, fanfic,
   book, game, character, ship, podcast, video-essay, anders),
   initiële intensity (1–10), optionele notitie, publiek/privé-toggle.

2) Day counter
   Auto-berekend uit `started_at`. Toont "Day N" en telt elke
   dag verder.

3) Status
   Een enum die de gebruiker handmatig kiest om de bewustzijnsfase
   te markeren: "Day 1", "Obsessing", "On loop", "Fading", "Post-fix",
   "Ended", "Dormant", "Send help".

4) Intensity-meter
   Schaal 1–10, met semantische labels (8–9 "deeply unwell",
   10 "send help"). Kleurcodering: teal voor laag, oranje voor
   midden, rood voor hoog.

5) Tags
   Komma-gescheiden, doorzoekbare labels.

6) Banner-afbeelding
   Per fix optioneel een banner. Kies een uit de gallery van 24
   presets of upload een eigen afbeelding.

7) Privacy
   Per fix in te stellen. Publieke fixes:
   - Verschijnen op je profiel
   - Hebben een eigen URL /fix/[id]
   - Zijn doorzoekbaar in /explore
   - Kunnen reacties en comments krijgen

8) Beëindigen
   Markeer als "Ended" en schrijf een eulogy. Pro-gebruikers
   kunnen Claude AI een eulogy laten genereren op basis van titel,
   categorie, intensity, tags en duur.

9) Graveyard
   Beëindigde fixes komen automatisch in de graveyard terecht.

10) Verwijderen
    Iedere gebruiker kan zijn eigen fixes hard verwijderen.

--- 7.2 Dagelijkse check-ins ---

- Eén check-in per fix per dag (unique constraint op fix_id + date).
- Log de intensity van die dag (los van de "huidige" intensity op de fix).
- Optionele notitie.
- Drijft de sparkline (lijngrafiek over de tijd).
- Een "checked in today"-vinkje verschijnt op de fix-detailpagina.

--- 7.3 Streaks & heatmap ---

Streak
   Het aantal opeenvolgende dagen dat de gebruiker minstens één
   check-in heeft gedaan op een willekeurige fix. Toont "current"
   en "longest".

Heatmap
   GitHub-stijl raster van 13 weken (90 dagen) waarin elke dag
   gekleurd is op basis van het aantal check-ins.

Statistieken
   Totaal aantal check-ins, langste streak, gemiddelde intensity
   per categorie (Pro).

--- 7.4 Sparkline ---

- Intensity over een 14-daags venster.
- Smooth cubic-bezier path SVG.
- Gradient fill teal naar transparant.
- Hover-tooltip (Pro).

--- 7.5 Share cards ---

Generatie
   Via /api/share/[id] of /api/card/[id] (Next.js edge function met
   next/og ImageResponse). Resolutie 1080×1920 (9:16, perfect voor
   Instagram Stories en TikTok).

Stijlen
   - paper:   crème achtergrond, serif display, retro-newspaper
              gevoel (gebruikt in de iconische landing-mockup —
              inmiddels uit de UI gehaald maar nog wel een
              template)
   - dark:    de standaard Hyperfix-look (zwart met teal bloom)
   - minimal: alleen type, geen achtergrond
   - photo:   gebaseerd op de banner-afbeelding van de fix

Inhoud
   - Titel
   - Day count (groot, teal)
   - Intensity bar of getal
   - Categorie-icoon
   - Gebruikersnaam
   - "tracked on hyperfix.app"

Export
   Download als PNG of via native iOS/Android share sheet.

Customization
   In /dashboard/fix/[id]/card kun je het template kiezen.
   Wordt opgeslagen in fixes.card_style.

--- 7.6 Publiek profiel /u/[username] ---

- Avatar, bio, banner, accent-kleur (Pro)
- Tot 3 pinned fixes (Pro) of 1 pinned (Free)
- Grid van publieke fixes
- Followers/following counts (klikbaar)
- Follow- en message-knop
- Optionele social links
- Aparte /graveyard subpagina

--- 7.7 Publieke fixpagina /fix/[id] ---

- Read-only weergave van de fix
- Reacties (één emoji per gebruiker)
- Comments (max 500 tekens, eigen comments verwijderbaar)
- Sparkline
- Link naar het profiel van de maker
- Eigen OG-image voor het delen

--- 7.8 Reacties ---

- Gecureerde set emoji's (geen vrije input)
- Eén emoji per user per fix (toevoegen/verwijderen/wisselen)
- Aggregated count per emoji
- Real-time updates via Supabase subscriptions
- Triggert notificatie naar de eigenaar van de fix

--- 7.9 Comments ---

- Alleen op publieke fixes
- Toont username, avatar, display name
- Relatieve tijdstempels ("3h ago", "just now")
- Eigen comments verwijderbaar; eigenaar van de fix kan
  modereren.
- Max 500 tekens.

--- 7.10 Graveyard ---

- /dashboard/graveyard (eigen) of /u/[username]/graveyard (publiek)
- Grid van beëindigde fixes met eulogy-snippets
- Filters per categorie
- Statistieken: totaal beëindigd, gemiddelde duur, categorie-
  verdeling, "most mourned"
- Pro: exporteer als JSON

--- 7.11 Eulogies ---

- Handmatig: maximaal 2000 tekens vrije tekst.
- AI-gegenereerd (Pro): Claude API neemt titel, categorie,
  intensity, tags en duur en schrijft een afscheid.
- Opgeslagen in fixes.eulogy, doorzoekbaar.

--- 7.12 Followers ---

- Volg publieke profielen.
- "Following"-tab in /explore toont recente fixes van mensen
  die je volgt.
- Notificatie bij nieuwe follower.

--- 7.13 Direct messages ---

- Per gebruikerspaar één conversatie (deterministisch via
  user_a < user_b).
- Berichten 1–2000 tekens, met read-status.
- Inbox in /dashboard/messages, thread in
  /dashboard/messages/[id].
- Ongelezen-badge op de nav (polling).

--- 7.14 Notificaties ---

Types: reaction, follow, milestone, message, streak.
Read/unread per gebruiker te markeren.
Te zien in /dashboard/notifications.
Push-notificaties via PWA (opt-in).

--- 7.15 Referral-systeem ---

- Iedere gebruiker krijgt automatisch een referral_code
  (eerste 8 tekens van het user-id).
- /join?ref=[code] slaat de code op in localStorage en
  redirect naar signup.
- Server-side validatie bij account-creatie zet
  profiles.referred_by.
- profiles.referral_count telt hoeveel mensen je hebt
  aangedragen.
- Beloningen zijn gepland (nog niet uitgerold).

--- 7.16 Wrapped (jaarrecap) ---

- /wrapped/[year], default huidig jaar.
- Statistieken: totaal aantal fixes, dagen, categorieën,
  langste fix, meest intense, langste streak.
- Deelbare image via /api/wrapped/image.

18. SAMENVATTING
================================================================================

Hyperfix is een full-stack moderne web-app gebouwd op Next.js 16,
React 19, Supabase en Stripe, die het concept van een hyperfixatie
als trackbaar fenomeen behandelt. De gebruiker logt een obsessie,
ziet de dagen oplopen, doet dagelijkse check-ins, deelt deelbare
9:16 cards op social media, ontvangt reacties en comments van
anderen, en archiveert beëindigde fixes met een eulogy in de
graveyard.

Het bedrijfsmodel is freemium: tot drie actieve fixes en de
hoofdfeatures zijn gratis voor altijd, Pro à $5/maand of $39/jaar
geeft onbeperkte fixes, AI-eulogies, custom accent-kleuren,
profielbanners, premium card templates, volledige analytics en
data-export.

De visuele identiteit is bewust editorial en dark: bijna-zwart
(#070708), één signature teal (#5EEAD4), Fraunces als display
serif, Instrument Sans als body, JetBrains Mono voor labels.
Subtiele grain-overlays en teal-bloom radial gradients geven
het z'n karakteristieke "obsessie-gloed".

De app is volledig responsive, installeerbaar als PWA, ondersteunt
push-notificaties, OAuth-login, en publiceert ongeveer honderd
voorgemaakte SEO-pagina's via /track/[slug] voor populaire
onderwerpen. Onder de motorkap zit Supabase PostgreSQL met
twaalf tabellen (alles met Row Level Security), zestig+ API-routes
(waarvan veel edge-functions voor dynamische beeldgeneratie),
en een groeiende set sociale features (followers, comments,
reacties, DMs, notifications).

Met andere woorden: Hyperfix is een dagboek voor de chronisch
geobsedeerde, gebouwd met de aandacht voor detail en de
verzorgde esthetiek van een product dat zichzelf serieus neemt
zonder ooit z'n humor te verliezen.
